RoundMaster - offline web app
==============================

Upload EVERYTHING in this folder (keep the folders as they are) to your web host,
e.g. a GitHub Pages repository. Then open the web address in Safari on each iPad
and use Share > Add to Home Screen.

Files:
  index.html             the app
  sw.js                  keeps a copy on the device so it works without internet
  manifest.webmanifest   name and icon for the Home Screen
  icons/                 app icons
  vendor/                styling and icons used by the app (stored locally)

Updating later: replace index.html and sw.js with the new ones and upload.
Open the app once while online, close it, and open it again.

Your patient data is NOT in these files. It stays on each device.
Use Settings > Data & Backup > Export to keep a backup or move data between devices.
